# 快速开始

欢迎使用PetPal！无论你是猫奴还是狗爸，PetPal都能帮你更好地照顾毛孩子。

## 注册账号

1. 打开App或访问Web端 [app.petpal.com](https://app.petpal.com)
2. 点击“注册”，输入手机号
3. 获取验证码并填写，设置密码
4. 点击完成，自动登录

![注册流程](/images/signup.gif)

## 添加宠物

登录后，点击首页的“添加宠物”：
- 填写宠物昵称、品种、生日
- 上传一张可爱的照片
- 点击保存

现在你可以开始记录宠物的日常啦！

## 常见问题

**收不到验证码怎么办？**  
请检查手机是否拦截了短信，或尝试点击“语音验证码”。

**忘记密码？**  
在登录页点击“忘记密码”，按提示重置即可。
