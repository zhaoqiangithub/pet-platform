# PawLink智能匹配

## 用户故事

### US-021：领养匹配推荐

**作为** 领养者
**我想要** 系统根据我的偏好为我推荐合适的宠物
**以便** 快速找到心仪的领养对象

**验收标准**：
- [ ] 系统记录用户浏览、收藏、咨询行为
- [ ] 首页显示"为你推荐"模块（最多6条）
- [ ] 推荐算法考虑：浏览历史、收藏偏好、位置、年龄偏好
- [ ] 用户可以设置领养偏好（品种、年龄、体型）
- [ ] 用户可以刷新推荐内容
- [ ] 用户可以关闭个性化推荐

### US-022：救助响应匹配

**作为** 志愿者
**我想要** 系统根据我的位置和技能推荐附近的救助任务
**以便** 及时参与救助行动

**验收标准**：
- [ ] 志愿者可设置自己的技能标签（救助、运输、医疗）
- [ ] 系统根据志愿者位置推荐3km内的救助任务
- [ ] 紧急救助任务优先推送给距离近、有相关技能的志愿者
- [ ] 推送通知可自定义开关

### US-023：成功领养预测

**作为** 平台运营方
**我想要** 系统能够预测领养成功率
**以便** 优化匹配算法，提高领养成功率

**验收标准**：
- [ ] 系统根据宠物信息（品种、年龄、健康状况）和领养者条件进行匹配度评分
- [ ] 匹配度评分显示在领养信息详情页
- [ ] 运营后台可查看匹配成功率统计数据
- [ ] 算法持续优化，基于实际领养结果

## 涉及服务

- recommendation-service（推荐服务）- 新建
- feed-service（动态服务）

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/v1/recommendations | 获取智能推荐 |
| GET | /api/v1/recommendations/rescue | 获取救助任务推荐 |
| GET | /api/v1/recommendations/match-score | 获取匹配度评分 |
| PUT | /api/v1/user/preferences | 设置用户偏好 |
