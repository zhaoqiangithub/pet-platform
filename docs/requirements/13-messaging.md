# PawLink一对一沟通

## 用户故事

### US-014：站内私信

**作为** 领养者/志愿者/爱心人士
**我想要** 与信息发布者进行站内私信沟通
**以便** 询问宠物详情、表达领养意愿、协调救助事宜

**验收标准**：
- [ ] 用户可以发送私信给信息发布者
- [ ] 支持文字消息
- [ ] 支持发送图片
- [ ] 支持发送位置信息
- [ ] 消息已读/未读状态清晰
- [ ] 消息列表按时间倒序排列
- [ ] 支持查看历史对话记录
- [ ] 未读消息数量在首页图标显示
- [ ] 新消息推送通知（需在设置中开启）

### US-015：快速联系

**作为** 领养者/志愿者
**我想要** 快速联系到信息发布者
**以便** 紧急情况下尽快沟通

**验收标准**：
- [ ] 信息详情页显示"联系Ta"按钮
- [ ] 点击可选择：站内私信、电话联系、微信号
- [ ] 电话联系点击后直接拨打（需用户授权）
- [ ] 微信联系可一键复制微信号
- [ ] 快速联系会记录在聊天记录中
- [ ] 每日快速联系次数限制（防骚扰）：最多20次

### US-016：举报机制

**作为** 发现违规/虚假信息的用户
**我想要** 举报可疑信息或用户
**以便** 维护平台秩序和可信度

**举报类型：
- [ ] 虚假信息
- [ ] 虐待动物
- [ ] 骚扰行为
- [ ] 诈骗行为
- [ ] 其他

**举报流程：
- [ ] 信息详情页和用户主页都有"举报"入口
- [ ] 举报时需选择举报类型
- [ ] 举报时需填写详细说明（必填，20字以上）
- [ ] 提交举报后，发送确认通知
- [ ] 举报处理结果通过站内通知告知（7个工作日内）
- [ ] 恶意举报会被记录并影响信用分

### US-017：黑名单

**作为** 不想接收某用户消息的用户
**我想要** 将某用户加入黑名单
**以便** 屏蔽骚扰和不想接收的消息

**验收标准**：
- [ ] 用户可以将其他用户加入黑名单
- [ ] 被拉黑后，发送消息会被系统拦截
- [ ] 拉黑时可选择是否同时举报
- [ ] 用户可以在设置中查看和管理黑名单
- [ ] 支持移除黑名单

## 涉及服务

- user-service（用户服务）
- message-service（消息服务）- 新建
- notification-service（通知服务）

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/v1/messages | 获取消息列表 |
| GET | /api/v1/messages/{conversationId} | 获取对话详情 |
| POST | /api/v1/messages/send | 发送消息 |
| POST | /api/v1/messages/{conversationId}/read | 标记已读 |
| POST | /api/v1/messages/quick-contact | 快速联系 |
| POST | /api/v1/messages/report | 举报用户/信息 |
| POST | /api/v1/messages/block | 加入黑名单 |
| GET | /api/v1/messages/block-list | 获取黑名单列表 |
| DELETE | /api/v1/messages/block/{userId} | 移除黑名单 |

## 优先级

P1（重要功能，促进交易/救助达成）

## 备注

- 私信是连接救助者和领养者的关键功能
- 需要防止骚扰，引入限流和举报机制
- 消息需要支持多端同步
