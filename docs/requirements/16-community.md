# PawLink社区功能

## 用户故事

### US-024：社区动态浏览

**作为** 平台用户
**我想要** 浏览社区中的救助故事和经验分享
**以便** 了解成功案例、学习救助知识、增强参与感

**验收标准**：
- [ ] 首页显示"社区"入口
- [ ] 社区动态信息流按时间倒序排列
- [ ] 支持下拉刷新和上拉加载更多
- [ ] 动态包含：文字、图片、视频（可选）
- [ ] 用户可以点赞、收藏动态
- [ ] 用户可以评论动态
- [ ] 用户可以关注其他用户
- [ ] 关注用户的动态会在信息流中优先显示

### US-025：发布救助故事

**作为** 成功领养者/志愿者
**我想要** 分享自己的救助/领养经历
**以便** 激励更多爱心人士参与救助

**验收标准**：
- [ ] 已完成实名认证的用户可以发布故事
- [ ] 故事可包含：文字（最多2000字）、图片（最多9张）
- [ ] 发布时可添加话题标签（#领养故事 #救助经验 #医疗知识）
- [ ] 故事发布后进入信息流
- [ ] 优质故事可能被推荐到首页

### US-026：成功案例展示

**作为** 平台运营方
**我想要** 展示成功领养的案例
**以便** 激励更多用户参与领养、验证平台价值

**验收标准**：
- [ ] 首页有"成功案例"展示区
- [ ] 案例包含：领养前后对比照片、领养者故事、宠物现状
- [ ] 成功领养后可自动生成案例（需用户授权）
- [ ] 成功案例可分享到其他社交平台
- [ ] 每周精选案例在首页置顶

### US-027：用户关注与粉丝

**作为** 平台用户
**我想要** 关注其他用户并查看他们的动态
**以便** 追踪喜欢的领养者/志愿者

**验收标准**：
- [ ] 用户可以关注其他用户
- [ ] 用户可以查看自己的粉丝列表
- [ ] 用户可以查看自己的关注列表
- [ ] 用户可以取消关注
- [ ] 关注列表和粉丝列表支持分页

## 涉及服务

- feed-service（动态服务）
- user-service（用户服务）
- notification-service（通知服务）

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/v1/feed | 获取社区信息流 |
| POST | /api/v1/feed/publish | 发布动态 |
| GET | /api/v1/feed/{id} | 获取动态详情 |
| POST | /api/v1/feed/{id}/like | 点赞 |
| POST | /api/v1/feed/{id}/unlike | 取消点赞 |
| POST | /api/v1/feed/{id}/comment | 评论 |
| POST | /api/v1/feed/{id}/share | 分享 |
| POST | /api/v1/user/{userId}/follow | 关注用户 |
| DELETE | /api/v1/user/{userId}/follow | 取消关注 |
| GET | /api/v1/user/{userId}/followers | 获取粉丝列表 |
| GET | /api/v1/user/{userId}/following | 获取关注列表 |
