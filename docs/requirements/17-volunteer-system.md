# PawLink志愿者管理系统

## 用户故事

### US-028：志愿者任务浏览与认领

**作为** 认证志愿者
**我想要** 浏览和认领救助任务
**以便** 参与实际的救助行动

**验收标准**：
- [ ] 已认证的志愿者可以浏览可认领的任务
- [ ] 任务列表按距离和紧急程度排序
- [ ] 任务详情包含：任务描述、地点、时间要求、所需技能、积分奖励
- [ ] 志愿者可以一键认领任务
- [ ] 同一任务可被多名志愿者认领，按先到先得或技能匹配分配
- [ ] 志愿者可以查看自己已认领的任务列表

### US-029：任务完成与评价

**作为** 认领任务的志愿者
**我想要** 完成任务并获得评价
**以便** 获得积分奖励和成就感

**验收标准**：
- [ ] 志愿者完成任务后可以提交完成申请
- [ ] 提交时需上传任务完成证明（照片/定位）
- [ ] 任务发布者或平台可确认任务完成
- [ ] 任务完成后，志愿者可获得积分奖励
- [ ] 任务发布者可以对志愿者进行评价（1-5星）
- [ ] 志愿者可以在个人中心查看任务记录和积分

### US-030：志愿者积分体系

**作为** 平台运营方
**我想要** 建立志愿者积分激励体系
**以便** 提高志愿者活跃度和参与度

**积分获取途径：
- [ ] 完成救助任务：基础积分+难度加成
- [ ] 发布优质救助信息：+10积分
- [ ] 成功帮助领养：+50积分
- [ ] 每日签到：+2积分
- [ ] 社区被点赞：+1积分/次

**积分用途：
- [ ] 积分可以兑换平台周边（徽章、纪念品）
- [ ] 积分可以抵扣部分服务费用
- [ ] 高积分志愿者优先获得任务推荐
- [ ] 年度积分榜排名前列可获得实物奖励

**验收标准**：
- [ ] 用户可以查看当前积分余额
- [ ] 用户可以查看积分获取记录
- [ ] 用户可以查看积分消费记录
- [ ] 积分排行榜可查看周榜/月榜/年榜
- [ ] 积分规则对所有用户可见

### US-031：志愿者技能认证

**作为** 有专业技能的志愿者
**我想要** 获得平台技能认证
**以便** 参与需要专业技能的任务并获得更高积分

**技能类型：
- [ ] 医疗技能：宠物急救、基础医疗知识
- [ ] 运输技能：自有车辆，可运输动物
- [ ] 救助技能：专业流浪动物救助经验
- [ ] 驯养技能：宠物行为训练能力

**验收标准**：
- [ ] 志愿者可以申请技能认证
- [ ] 申请时需提供证明材料（证书、经验证明）
- [ ] 技能认证需人工审核
- [ ] 认证通过后获得对应技能标签
- [ ] 拥有技能标签的志愿者优先匹配相关任务
- [ ] 技能标签在个人主页显示

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/v1/volunteer/tasks | 获取可认领任务列表 |
| GET | /api/v1/volunteer/tasks/{id} | 获取任务详情 |
| POST | /api/v1/volunteer/tasks/{id}/claim | 认领任务 |
| POST | /api/v1/volunteer/tasks/{id}/complete | 提交完成 |
| POST | /api/v1/volunteer/tasks/{id}/confirm | 确认完成 |
| POST | /api/v1/volunteer/tasks/{id}/evaluate | 评价志愿者 |
| GET | /api/v1/volunteer/my-tasks | 我的任务列表 |
| GET | /api/v1/volunteer/points | 获取积分余额 |
| GET | /api/v1/volunteer/points/history | 积分记录 |
| GET | /api/v1/volunteer/rankings | 积分排行榜 |
| POST | /api/v1/volunteer/skills/apply | 申请技能认证 |
| GET | /api/v1/volunteer/skills | 我的技能认证 |

## 优先级

P3（高级功能，志愿者组织难度高）
