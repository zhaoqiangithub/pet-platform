# PawLink支付与众筹

## 用户故事

### US-018：众筹医疗费用

**作为** 救助者/志愿者
**我想要** 为受伤/生病的流浪动物发起医疗众筹
**以便** 筹集治疗费用，提高救助成功率

**验收标准**：
- [ ] 已完成实名认证的用户可以发起众筹
- [ ] 众筹需提供：目标金额、受益动物信息、治疗医院、预算明细
- [ ] 众筹需上传动物现状照片/视频作为证明
- [ ] 众筹需选择目标金额和截止时间（7-30天）
- [ ] 众筹发起后需经过审核（1-2个工作日）
- [ ] 捐款人可以查看众筹详情和资金使用情况
- [ ] 众筹成功后将款项直接支付给合作医院
- [ ] 众筹失败（未达目标）时自动退款给捐款人
- [ ] 众筹页面显示进展和捐款人名单（匿名可选项）
- [ ] 众筹成功/失败自动发送通知给捐款人

### US-019：在线捐款

**作为** 爱心人士
**我想要** 为救助的动物捐款
**以便** 贡献自己的力量帮助流浪动物

**验收标准**：
- [ ] 支持微信支付和支付宝
- [ ] 捐款时可选择金额或自定义金额
- [ ] 捐款时可留署名（可选择匿名）
- [ ] 捐款成功后收到电子收据
- [ ] 捐款后可获得平台积分奖励
- [ ] 可以在个人中心查看捐款记录

### US-020：志愿者补贴发放

**作为** 平台方/救助机构
**我想要** 为参与救助的志愿者发放补贴
**以便** 激励志愿者参与救助行动

**验收标准**：
- [ ] 救助机构可以申请为志愿者发放补贴
- [ ] 补贴金额需在平台设定的范围内
- [ ] 补贴发放需经过平台审核
- [ ] 志愿者可以查看补贴收入记录
- [ ] 补贴通过平台支付给志愿者（微信/支付宝）

## 涉及服务

- payment-service（支付服务）- 新建
- crowdfunding-service（众筹服务）- 新建
- user-service（用户服务）

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/v1/crowdfunding/create | 创建众筹 |
| GET | /api/v1/crowdfunding/{id} | 获取众筹详情 |
| POST | /api/v1/crowdfunding/{id}/donate | 捐款 |
| GET | /api/v1/crowdfunding/{id}/donations | 获取捐款记录 |
| GET | /api/v1/crowdfunding/my | 我的众筹 |
| POST | /api/v1/payment/create-order | 创建支付订单 |
| POST | /api/v1/payment/callback | 支付回调 |
| GET | /api/v1/payment/history | 支付记录 |
| POST | /api/v1/volunteer/subsidy/apply | 申请志愿者补贴 |
