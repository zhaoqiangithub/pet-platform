# 用户认证模块需求

## 用户故事

### US-001：用户注册
**作为** 一名新用户  
**我想要** 使用手机号注册账号  
**以便** 成为平台用户并使用宠物服务

**验收标准**：
- 输入手机号，点击获取验证码，收到6位数字验证码短信
- 输入验证码、密码（至少8位，含字母数字）、昵称（可选）
- 点击注册，成功创建账号并自动登录
- 手机号不能重复注册，重复时提示“该手机号已注册”
- 密码需加密存储

### US-002：用户登录
**作为** 已注册用户  
**我想要** 使用手机号+密码或验证码登录  
**以便** 访问我的个人信息和宠物

**验收标准**：
- 支持密码登录和验证码登录两种方式
- 密码错误超过5次，账户临时锁定15分钟
- 登录成功后返回JWT令牌，有效期7天
- 登录失败返回具体错误信息（“手机号不存在”或“密码错误”）
