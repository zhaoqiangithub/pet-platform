# PawLink用户认证系统

## 用户故事

### US-001：普通用户注册与登录

**作为** 一名新用户
**我想要** 使用手机号注册账号并完成实名认证
**以便** 成为平台用户并使用宠物救助/领养服务

**验收标准**：
- [ ] 用户可以使用手机号注册账号
- [ ] 注册时需设置密码（至少8位，含字母数字）
- [ ] 注册成功后自动登录，返回JWT令牌
- [ ] 手机号不能重复注册，重复时提示"该手机号已注册"
- [ ] 密码需加密存储（BCrypt）
- [ ] 用户可以使用手机号+密码登录
- [ ] 登录成功后返回JWT令牌，有效期7天

### US-002：实名认证

**作为** 已注册普通用户
**我想要** 完成实名认证（身份证+人脸识别）
**以便** 提升账号可信度，有资格发布救助/领养信息

**验收标准**：
- [ ] 用户可以上传身份证照片（正反面）
- [ ] 用户可以完成人脸识别验证
- [ ] 实名认证通过后，获得信用分加成（+10分）
- [ ] 用户可以在个人中心查看认证状态
- [ ] 认证失败时，用户可以看到拒绝原因并重新申请

### US-003：志愿者认证

**作为** 有救助经验的爱心人士
**我想要** 申请成为认证志愿者
**以便** 参与平台救助活动、认领救助任务

**验收标准**：
- [ ] 已实名认证的用户可以申请志愿者认证
- [ ] 申请时需填写技能信息（救助技能、医疗基础等）
- [ ] 申请时需同意背景调查
- [ ] 志愿者认证需人工审核，3个工作日内完成
- [ ] 审核结果通过站内通知告知
- [ ] 认证通过后获得志愿者标识和额外信用分（+20分）

### US-004：救助机构认证

**作为** 救助站/宠物医院负责人
**我想要** 完成机构认证
**以便** 在平台发布救助信息、申请合作

**验收标准**：
- [ ] 已注册用户可以申请机构认证
- [ ] 申请时需上传营业执照照片
- [ ] 申请时需填写机构基本信息（名称、地址、联系方式）
- [ ] 机构认证需人工审核和实地验证，5个工作日内完成
- [ ] 审核结果通过站内通知告知
- [ ] 认证通过后获得机构蓝V标识

### US-005：忘记密码

**作为** 忘记密码的已注册用户
**我想要** 通过手机验证码重置密码
**以便** 恢复账号访问

**验收标准**：
- [ ] 用户可以点击"忘记密码"
- [ ] 输入手机号，获取6位验证码
- [ ] 验证通过后，可设置新密码
- [ ] 密码重置成功后自动登录

## 涉及服务

- user-service（用户服务）
- notification-service（通知服务）

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/v1/auth/register | 用户注册 |
| POST | /api/v1/auth/login | 用户登录 |
| POST | /api/v1/auth/logout | 用户登出 |
| POST | /api/v1/auth/reset-password | 忘记密码 |
| POST | /api/v1/auth/send-code | 发送验证码 |
| POST | /api/v1/auth/real-name-auth | 实名认证 |
| POST | /api/v1/auth/volunteer-auth | 志愿者认证申请 |
| POST | /api/v1/auth/organization-auth | 机构认证申请 |
| GET | /api/v1/auth/status | 获取认证状态 |

## 优先级

P0（核心功能，必须优先实现）

## 备注

- 信用分系统将为后续功能提供基础
