# PawLink搜索与过滤

## 用户故事

### US-010：基础搜索

**作为** 领养者/爱心人士
**我想要** 搜索符合条件的宠物信息
**以便** 快速找到心仪的领养对象或救助目标

**验收标准**：
- [ ] 支持关键字搜索（宠物名称、描述、品种）
- [ ] 搜索结果按相关性和时间排序
- [ ] 搜索结果支持分页（每页20条）
- [ ] 无结果时显示"暂无相关内容"和推荐建议
- [ ] 搜索响应时间<500ms

### US-011：领养信息筛选

**作为** 正在寻找宠物的领养者
**我想要** 按多种条件筛选领养信息
**以便** 精准找到符合要求的宠物

**验收标准**：
- [ ] 支持按动物类型筛选：猫、狗、其他
- [ ] 支持按品种筛选（支持搜索）
- [ ] 支持按年龄筛选：幼年（<1岁）、成年（1-7岁）、老年（>7岁）
- [ ] 支持按性别筛选：公、母
- [ ] 支持按体型筛选：小型、中型、大型
- [ ] 支持按健康状况筛选：已疫苗、已驱虫、已绝育
- [ ] 支持按距离筛选：1km、3km、5km、10km、全城
- [ ] 支持按发布时间筛选：今天、近3天、近一周
- [ ] 筛选条件可多选组合
- [ ] 筛选结果实时更新，显示符合条件数量

### US-012：救助信息筛选

**作为** 想要参与救助的志愿者
**我想要** 按紧急程度和距离筛选救助信息
**以便** 快速响应需要帮助的动物

**验收标准**：
- [ ] 支持按紧急程度筛选：紧急、一般
- [ ] 支持按动物类型筛选：猫、狗、其他
- [ ] 支持按距离筛选：1km、3km、5km、10km
- [ ] 支持按发布时间筛选：今天、近24小时、近3天
- [ ] 紧急救助信息置顶显示
- [ ] 筛选结果实时更新

### US-013：智能推荐

**作为** 领养者
**我想要** 根据我的浏览历史和偏好获得智能推荐
**以便** 发现可能感兴趣的宠物

**验收标准**：
- [ ] 系统记录用户浏览、收藏、咨询行为
- [ ] 首页显示"为你推荐"模块（最多6条）
- [ ] 推荐算法考虑：浏览历史、收藏偏好、位置
- [ ] 用户可以刷新推荐内容
- [ ] 用户可以关闭个性化推荐

## 涉及服务

- feed-service（动态服务）
- search-service（搜索服务）- 新建
- recommendation-service（推荐服务）- 新建

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/v1/search | 通用搜索 |
| GET | /api/v1/adoption/filter | 领养信息筛选 |
| GET | /api/v1/rescue/filter | 救助信息筛选 |
| GET | /api/v1/recommendations | 获取智能推荐 |
