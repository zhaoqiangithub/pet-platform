# PawLink地图与信息发布

## 用户故事

### US-006：地图展示救助/领养信息

**作为** 爱心人士/领养者/志愿者
**我想要** 在地图上查看附近需要帮助的动物或待领养的宠物
**以便** 快速了解身边救助情况，参与救助或领养

**验收标准**：
- [ ] 地图默认定位到用户当前位置
- [ ] 地图上显示不同颜色的标记区分信息状态：
  - 红色：紧急救助
  - 黄色：需要救助
  - 绿色：待领养
  - 蓝色：已领养/已完成
- [ ] 点击标记可以查看详细信息卡片
- [ ] 信息卡片包含：动物照片、类型、状态、发布时间、位置
- [ ] 支持热力图模式显示救助密度
- [ ] 支持半径筛选（如1km、5km、10km）
- [ ] 实时性：新信息发布后5分钟内显示在地图上

### US-007：发布救助信息

**作为** 发现流浪动物的爱心人士
**我想要** 发布标准化救助信息
**以便** 让更多人和志愿者看到并参与救助

**验收标准**：
- [ ] 发布入口明显（首页+个人中心）
- [ ] 需先完成实名认证才能发布
- [ ] 必填信息：
  - 位置（自动获取，支持手动调整）
  - 动物类型（猫/狗/其他）
  - 动物状态（健康/受伤/生病）
  - 现场照片（至少1张，最多9张）
  - 联系方式
- [ ] 选填信息：描述、品种、年龄
- [ ] 提交后进入AI辅助审核（重复信息检测）
- [ ] 审核通过后立即显示在地图上
- [ ] 审核未通过时，发送站内通知并说明原因

### US-008：发布领养信息

**作为** 临时救助者/救助机构
**我想要** 发布待领养宠物信息
**以便** 为救助的动物寻找合适的家庭

**验收标准**：
- [ ] 发布入口明显（首页+个人中心）
- [ ] 需先完成实名认证才能发布
- [ ] 必填信息：
  - 宠物照片（至少1张，最多9张）
  - 品种
  - 年龄（幼年/成年/老年）
  - 性别
  - 性格描述
  - 健康状况（是否疫苗、驱虫、绝育）
  - 领养要求
  - 联系方式
- [ ] 选填信息：名字、救助故事
- [ ] 提交后需人工审核或AI辅助审核
- [ ] 审核通过后显示在地图和领养列表中

### US-009：更新信息状态

**作为** 救助信息发布者
**我想要** 更新已发布信息的状态
**以便** 让关注者了解最新进展

**验收标准**：
- [ ] 用户可以更新自己发布的信息状态
- [ ] 可选状态：待救助中、已救助、已送医、已领养、已结束
- [ ] 更新状态时可添加进展描述和照片
- [ ] 状态更新后，地图标记颜色自动改变
- [ ] 状态更新自动通知关注该信息的用户

## 涉及服务

- user-service（用户服务）
- feed-service（动态服务）
- map-service（地图服务）- 新建
- notification-service（通知服务）

## API端点

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/v1/map/points | 获取地图上的信息点 |
| GET | /api/v1/map/heatmap | 获取热力图数据 |
| POST | /api/v1/rescue/publish | 发布救助信息 |
| POST | /api/v1/adoption/publish | 发布领养信息 |
| PUT | /api/v1/rescue/{id}/status | 更新救助信息状态 |
| PUT | /api/v1/adoption/{id}/status | 更新领养信息状态 |
| GET | /api/v1/rescue/{id} | 获取救助详情 |
| GET | /api/v1/adoption/{id} | 获取领养详情 |

## 优先级

P0（核心功能，必须优先实现）

## 备注

- 地图功能是平台的核心差异化功能
- 需要接入高德地图或百度地图API
- 信息审核机制是关键，可先用人工+规则，逐步引入AI
